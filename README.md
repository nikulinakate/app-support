# Sultonov Apps Support

Universal support website for iOS/iPadOS apps.

## Files
- `index.html` — Support / FAQ
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use
- `styles.css` — shared design

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `app-support`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save.

Your site will be available at:

`https://YOUR_GITHUB_USERNAME.github.io/app-support/`

Use:
- Support URL: `https://YOUR_GITHUB_USERNAME.github.io/app-support/`
- Privacy Policy URL: `https://YOUR_GITHUB_USERNAME.github.io/app-support/privacy.html`
- Terms of Use URL: `https://YOUR_GITHUB_USERNAME.github.io/app-support/terms.html`

## Important
This site is intentionally written for multiple apps. Before publishing an app, make sure the Privacy Policy accurately covers that app's actual data handling, SDKs, permissions, analytics, advertising, AI/cloud processing, and account features.
